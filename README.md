
# Gestor de estudiantes

## Descripción

Aplicación web desarrollada con Vue.js 3 utilizando
Options API para administrar estudiantes y sus
calificaciones.

Permite registrar estudiantes, validar información,
modificar calificaciones, eliminar registros,
aplicar filtros y consultar estadísticas del grupo.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Vue.js 3
- Options API

## Funcionalidades

1. Registro de estudiantes.
2. Validación de nombres, carreras y calificaciones.
3. Control de estudiantes duplicados.
4. Control de cupos máximos.
5. Modificación y eliminación de estudiantes.
6. Filtros por carrera, nombre y estado.
7. Resumen de calificaciones.
8. Eliminación de todos los registros.

## Estructura del proyecto

- index.html
- app.js
- styles.css
- README.md

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar index.html mediante Live Server.
4. Utilizar el gestor desde el navegador.

## Almacenamiento

Los estudiantes se almacenan en memoria mediante
data() de Vue. No se utiliza API, base de datos
ni almacenamiento persistente.
